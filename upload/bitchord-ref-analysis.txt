### **Summary of Animation Behavior**
1.  **The "Loading" Snap:** When skipping tracks, the app immediately **hard cuts** the background to a "neutral" or "default" color (often a medium grey like `#444` or `#555`) while showing the music note placeholder.
2.  **The "Artwork Reveal" Fade:** Once the new album artwork is downloaded/processed, the background performs a **smooth crossfade (approx. 300-500ms)** from that neutral color to the final dynamic color extracted from the image.
3.  **No Intermediate Flashes:** There are no rainbow flashes. The transition is strictly: `[Old Color] -> [Cut to Neutral] -> [Fade to New Color]`.

### **Concrete Implementation Plan**

To replicate the BITCHORD look exactly, use the following technical approach:

#### **1. Technique: Dynamic Palette Extraction + CSS Transitions**
You are not using pre-defined gradients. You must extract the dominant color from the album art in real-time (or cache it) and apply it to the background.

*   **Extraction Algorithm:** Use a library (like `Android-Palette` on native, or a JS implementation like `node-vibrant`/`color-thief` for React Native/Web) to extract the **Dominant Vibrant** or **Muted** color from the album bitmap.
*   **Color Processing:** The extracted color will likely be too bright. You must programmatically darken it.
    *   *Formula:* Reduce brightness by ~60-70% and slightly saturate it.
    *   *Goal:* Ensure the resulting hex code has enough contrast for white text (Luminance < 0.2).

#### **2. The "Two-Phase" State Machine**
You need to manage two distinct states for the background to get that specific "Snap then Fade" feel:

*   **State A: `isLoading` (or `artworkUrl` is null)**
    *   **Background Style:** Set to a static "Idle" color (e.g., `#3C3C3C`).
    *   **Animation:** **None (Instant)**.
    *   **UI:** Show the "Music Note" placeholder icon.
*   **State B: `isLoaded` (Artwork ready)**
    *   **Background Style:** Set to the dynamically calculated gradient (using the extracted color).
    *   **Animation:** **Transition: background-color 0.4s ease** (or opacity crossfade).

#### **3. Implementation Details (React Native / Web Example)**

**The Gradient Style:**
Do not use a flat color. Use a subtle linear gradient to give it depth.
*   **Top Color:** The extracted dominant color (darkened).
*   **Bottom Color:** The extracted color with **extra black mixed in** (e.g., `rgba(0,0,0,0.6)` blended over it, or simply shift the hue darker).
*   **Direction:** `toBottom` (180 degrees).

**The Code Logic (Pseudocode):**

```javascript
// State
const [bgColor, setBgColor] = useState('#333333'); // Default "Loading" grey
const [isArtReady, setIsArtReady] = useState(false);

// When Song Changes
const onSongChange = (newSong) => {
  1. setIsArtReady(false);
  2. // IMMEDIATELY snap to default grey (or let the UI unmount/remount)
  3. loadArtwork(newSong.url).then((bitmap) => {
     const palette = extractColor(bitmap); // Get Hex
     const darkPalette = darken(palette, 0.6); // Process it
     setBgColor(darkPalette);
     setIsArtReady(true); // Trigger re-render with transition
  });
}

// Render
<View style={[
  styles.container, 
  { 
    backgroundColor: bgColor,
    // The transition only applies when 'isArtReady' toggles true
    // Or use a dedicated animation library like Animated/API
  }
]}>
  { !isArtReady ? <PlaceholderIcon /> : <BlurredAlbumArt /> }
</View>
```

#### **4. Recommended Animation Settings**
*   **Duration:** **400ms** (This feels "snappy" but smooth. 300ms is too fast, 600ms feels sluggish).
*   **Easing:** **Ease-out** (Start fast, end slow) or **Cubic-bezier(0.4, 0.0, 0.2, 1)** (Standard Material deceleration).
*   **Album Art Treatment:** The album art itself should be blurred (Gaussian blur radius ~10-20px) and have a dark overlay (`rgba(0,0,0,0.3)`) so the white text pops. The background color you calculated serves as the "fallback" behind this blurry image.
